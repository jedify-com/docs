Jedify's MCP server exposes two modes. The connection and authentication are identical — the mode only changes which tools your client sees.

- **Asker** _(default)_ — natural language data analysis. Ask questions, get answers and charts.
- **Builder** — programmatic access to semantic functions and the TypeScript SDK for building dashboards and apps.

## Choose your mode

| | Asker mode | Builder mode |
| --- | --- | --- |
| **Best for** | Data analysts, business users, executives | Developers, data engineers, app builders |
| **Primary use** | Ad-hoc data exploration via questions | Building dashboards and data applications |
| **Interface** | Natural language questions | Semantic functions + TypeScript SDK |
| **Execution** | LLM generates SQL (2–5s) | Pre-built queries (under 500ms) |
| **Tools** | Questioning and analysis tools | Function management and SDK tools |

## Asker mode

Ask questions about your business data in plain language. Jedify interprets the question, generates SQL against your semantic layer, runs it, and returns an answer with charts and an explanation.

Best for data analysts, business users, and executives doing ad-hoc exploration, investigations, and reporting.

## Builder mode

Work with **semantic functions** — pre-built, parameterized queries you call by name — and the `@jedify/sdk` TypeScript SDK. Because the query is built ahead of time, execution is deterministic and fast (under 500ms), with no LLM step at runtime.

Best for developers building dashboards, embedded analytics, and data applications.

## Switching modes

Asker mode is the default — no flag needed. To run in Builder mode, add `--builder` to the proxy `args`:

```json
{
  "mcpServers": {
    "jedify": {
      "command": "npx",
      "args": ["-y", "@jedify/mcp-auth", "--builder"]
    }
  }
}
```

| `args` | Mode |
| --- | --- |
| `["-y", "@jedify/mcp-auth"]` | Asker _(default)_ |
| `["-y", "@jedify/mcp-auth", "--builder"]` | Builder |

See [Connect](connect) for where this config goes in each client, and [Authentication](authentication) for how to sign in.

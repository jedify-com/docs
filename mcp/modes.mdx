Jedify's MCP server exposes two modes. The connection and authentication are identical — the mode only changes which tools your client sees.

- **Asker** _(default)_ — ask questions in plain language; get data back.
- **Builder** — have your agent build data apps and dashboards using Jedify's semantic functions.

## Choose your mode

| | Asker mode | Builder mode |
| --- | --- | --- |
| **Best for** | Ad-hoc questions and analysis | Building dashboards and data apps |
| **How you use it** | You ask, in conversation | You describe; your agent builds |
| **Speed** | A few seconds — generated per question | Instant — prebuilt, no AI at runtime |
| **Tools your agent gets** | Questioning and analysis | The above, plus function management and SDK |

## Asker mode

Ask a question in plain language. Jedify interprets it against your semantic layer, runs the query, and returns the data. Best for ad-hoc exploration, investigations, and reporting.

## Switching modes

Asker mode is the default — no flag needed. To run in Builder mode, add `--builder` to the proxy `args`:

```json
{
  "mcpServers": {
    "jedify": {
      "command": "npx",
      "args": ["-y", "@jedify/mcp-auth", "--builder"]
    }
  }
}
```

| `args` | Mode |
| --- | --- |
| `["-y", "@jedify/mcp-auth"]` | Asker _(default)_ |
| `["-y", "@jedify/mcp-auth", "--builder"]` | Builder |

On a **hosted agent or app builder** (no local proxy), select Builder mode with the URL `https://be.jedify.com/mcp/sse?mode=builder` instead.

See [Connect](/mcp/connect) for the full setup in each client.

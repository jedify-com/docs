Jedify's MCP server runs at `https://be.jedify.com/mcp` — there is nothing to install. In **Claude**, Jedify is a set of connectors; **hosted agents and app builders** get the server URL and an API key. Both use the same [modes](/mcp/modes) and [authentication](/mcp/authentication).

<Note>
If your organization's Jedify is hosted in the EU, use `https://be-eu.jedify.com/mcp` wherever this page says `https://be.jedify.com/mcp`.
</Note>

## Claude

Jedify comes as **one connector per [mode](/mcp/modes)** — nothing to install or configure. Connect the one you need and sign in; you can connect more than one.

| Connector                    | Mode                  | What your agent gets                                              |
| ---------------------------- | --------------------- | ----------------------------------------------------------------- |
| **Jedify Production**         | Asker _(default)_     | Questions and analysis                                            |
| **Jedify Production Editor**  | Editor                | The above, plus semantic-layer editing, versioning, and test sets |
| **Jedify Production Builder** | Builder               | The above, plus semantic functions and the SDK                    |

<Note>
**Each mode is a separate connector.** Connecting **Jedify Production** gives your agent the Asker tools only; for Editor or Builder mode, connect that mode's connector as well.
</Note>

<Steps>
  <Step title="Find the connector">
    In Claude, open **Settings → Connectors** and search for **Jedify**. The Asker connector is also in the public directory at [claude.ai/directory/jedify](https://claude.ai/directory/jedify).
  </Step>
  <Step title="Connect and sign in">
    Click **Connect** on the connector for your mode. Your organization's Jedify login opens; sign in and return to Claude. Sessions refresh automatically — see [Authentication](/mcp/authentication).
  </Step>
</Steps>

![The Jedify connector in the Claude connector directory, showing the Asker tools and the Connected by default status](/images/docs/mcp/claude-directory-jedify.png)

On Claude Team and Enterprise, a workspace admin enables the connectors once for the whole organization — they then appear for every user, connected by default. Once connected, they are available wherever you use Claude: the web app, Claude Desktop, and Claude Code (run `/mcp` to see them).

<Note>
**Already using `@jedify/mcp-auth`?** Remove the `jedify` entry from your client's MCP configuration and use the connectors instead — the local proxy is no longer needed.
</Note>

To confirm the mode, ask Claude _"Which Jedify tools do you have?"_ — Editor mode includes `make_edit` and `get_graph`; Builder mode includes `create_semantic_function` and `list_semantic_functions`.

## Hosted agents and other MCP clients

For platforms that connect to an MCP server with a URL and a token — ChatGPT, no-code app builders, or any MCP client outside Claude — provide the server URL and an API key in the platform's MCP settings:

|                |                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Server URL** | `https://be.jedify.com/mcp` for Asker mode. Add `?mode=editor` or `?mode=builder` for the other modes — the URL is what selects the mode |
| **API key**    | Create one in Jedify under **Settings → API Keys** — see [Authentication](/mcp/authentication)                                           |

To confirm the mode, ask your agent _"Which Jedify tools do you have?"_ — Editor mode includes `make_edit` and `get_graph`; Builder mode includes `create_semantic_function` and `list_semantic_functions`.

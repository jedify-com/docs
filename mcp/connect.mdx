Jedify's MCP server runs at `https://be.jedify.com/mcp` — there is nothing to install. In **Claude**, Jedify is a connector; **hosted agents and app builders** get the server URL and an API key. Both use the same [modes](/mcp/modes) and [authentication](/mcp/authentication).

<Note>
If your organization's Jedify is hosted in the EU, use `https://be-eu.jedify.com/mcp` wherever this page says `https://be.jedify.com/mcp`.
</Note>

## Claude

Jedify is a connector in Claude — nothing to install or configure. Connect it and sign in.

<Steps>
  <Step title="Open the Jedify connector">
    Go to [claude.ai/directory/jedify](https://claude.ai/directory/jedify), or open **Settings → Connectors** in Claude and search for **Jedify**.
  </Step>
  <Step title="Connect and sign in">
    Click **Connect**. Your organization's Jedify login opens; sign in and return to Claude. Sessions refresh automatically — see [Authentication](/mcp/authentication).
  </Step>
</Steps>

![The Jedify connector in the Claude connector directory, showing its tools and the Connected by default status](/images/docs/mcp/claude-directory-jedify.png)

On Claude Team and Enterprise, a workspace admin enables the connector once for the whole organization — it then appears for every user, connected by default. Once connected, it is available wherever you use Claude: the web app, Claude Desktop, and Claude Code (run `/mcp` to see it).

<Note>
The Claude connector runs in **Asker** mode — questions and analysis. [Editor and Builder](/mcp/modes) modes are not yet available through it.
</Note>

<Note>
**Already using `@jedify/mcp-auth`?** Remove the `jedify` entry from your client's MCP configuration and use the connector instead — the local proxy is no longer needed.
</Note>

## Hosted agents and other MCP clients

For platforms that connect to an MCP server with a URL and a token — ChatGPT, no-code app builders, or any MCP client outside Claude — provide the server URL and an API key in the platform's MCP settings:

|                |                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Server URL** | `https://be.jedify.com/mcp` for Asker mode. Add `?mode=editor` or `?mode=builder` for the other modes — the URL is what selects the mode |
| **API key**    | Create one in Jedify under **Settings → API Keys** — see [Authentication](/mcp/authentication)                                           |

To confirm the mode, ask your agent _"Which Jedify tools do you have?"_ — Editor mode includes `make_edit` and `get_graph`; Builder mode includes `create_semantic_function` and `list_semantic_functions`.

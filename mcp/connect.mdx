Jedify's MCP server runs at `https://be.jedify.com/mcp` — there is nothing to install. In **Claude**, Jedify is a connector; **hosted agents and app builders** get the server URL and an API key. Both use the same [modes](/mcp/modes) and [authentication](/mcp/authentication).

<Note>
If your organization's Jedify is hosted in the EU, use `https://be-eu.jedify.com/mcp` wherever this page says `https://be.jedify.com/mcp`.
</Note>

## Claude

<Warning>
**Each mode is a separate connector.** The Jedify connector in Claude's directory runs in **Asker** mode. For **Editor** or **Builder** mode, add a custom connector with the mode in its URL, as described below — one per mode you need. Several can be connected side by side.
</Warning>

### Asker mode: from the connector directory

Jedify is listed in Claude's connector directory. Open [claude.ai/directory/jedify](https://claude.ai/directory/jedify) (also reachable from **Settings → Connectors** in Claude) and click **Connect**. Your organization's Jedify login opens; sign in and return to Claude.

![Jedify in the Claude connector directory, showing the Asker tools and the Connected by default status](/images/docs/mcp/claude-directory-jedify.png)

On Claude Team and Enterprise, a workspace admin can enable the connector once for the whole organization — it then appears for every user, connected by default.

### Editor and Builder modes: as a custom connector

<Steps>
  <Step title="Open the connector settings">
    In Claude, click **+** in the message box → **Connectors** → **Manage connectors** → **Add custom connector**.
  </Step>
  <Step title="Enter the server URL">
    Name it after the mode — for example **Jedify Editor** — and enter the mode's URL:

    | Mode                  | Server URL                                                                         |
    | --------------------- | ---------------------------------------------------------------------------------- |
    | **Editor**            | `https://be.jedify.com/mcp?mode=editor`                                            |
    | **Builder**           | `https://be.jedify.com/mcp?mode=builder`                                           |
    | **Asker** _(default)_ | `https://be.jedify.com/mcp` — only if the directory listing isn't available to you |

    Repeat for each mode you need.
  </Step>
  <Step title="Connect and sign in">
    Click **Add**, then **Connect**. Sign in with your Jedify login and return to Claude. Sessions refresh automatically — see [Authentication](/mcp/authentication).
  </Step>
</Steps>

Once added, the Jedify connectors appear alongside Claude's other connectors wherever you use Claude — the web app, Claude Desktop, and Claude Code (run `/mcp` to see them) — for every user your admin enabled them for.

<Note>
**Already using `@jedify/mcp-auth`?** Remove the `jedify` entry from your client's MCP configuration and use the connectors instead — the local proxy is no longer needed.
</Note>

To confirm the mode, ask Claude _"Which Jedify tools do you have?"_ — Editor mode includes `make_edit` and `get_graph`; Builder mode includes `create_semantic_function` and `list_semantic_functions`.

## Hosted agents and other MCP clients

For platforms that connect to an MCP server with a URL and a token — ChatGPT, no-code app builders, or any MCP client outside Claude — provide the server URL and an API key in the platform's MCP settings:

|                |                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Server URL** | `https://be.jedify.com/mcp` for Asker mode. Add `?mode=editor` or `?mode=builder` for the other modes — the URL is what selects the mode |
| **API key**    | Create one in Jedify under **Settings → API Keys** — see [Authentication](/mcp/authentication)                                           |

To confirm the mode, ask your agent _"Which Jedify tools do you have?"_ — Editor mode includes `make_edit` and `get_graph`; Builder mode includes `create_semantic_function` and `list_semantic_functions`.

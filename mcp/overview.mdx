The Model Context Protocol (MCP) is an open standard that lets AI agents connect securely to external data and tools. Jedify's MCP server gives your agent — **Claude Desktop**, **Cursor**, or a **hosted AI agent or app builder** — direct access to your organization's data through its semantic layer.

There are two [modes](modes):

- **Asker** _(default)_ — ask questions in plain language and get answers, charts, and explanations.
- **Builder** — have your agent build data apps and dashboards: it creates reusable **semantic functions** and writes the app code that calls them.

You steer your agent in plain language; it uses the Jedify tools. The connection and authentication are the same for both modes; the mode only changes which tools your agent gets.

## Key features

- **Secure authentication** — sign in through your organization, or use a user-bound API key.
- **Semantic layer access** — explore your data using business terminology, not raw tables.
- **Role-based access control** — every request is scoped to your user's permissions.

The Model Context Protocol (MCP) is an open standard that lets AI assistants and IDEs connect securely to external data sources and tools. Jedify's MCP server gives clients like Claude Desktop and Cursor direct access to your organization's semantic layer.

You connect through the `@jedify/mcp-auth` proxy. The same proxy serves two [modes](modes):

- **Asker** _(default)_ — natural language data analysis for analysts and business users.
- **Builder** — programmatic access to semantic functions and the TypeScript SDK for developers building dashboards and apps.

The connection and authentication are the same for both; the mode only changes which tools the client sees.

## Key features

- **Secure authentication** — sign in through your organization, or use a user-bound API key.
- **Semantic layer access** — explore your data using business terminology, not raw tables.
- **Role-based access control** — every request is scoped to your user's permissions.

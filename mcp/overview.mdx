The Model Context Protocol (MCP) lets an AI agent — Claude, Cursor, or a hosted agent or app builder — work with your Jedify data through its semantic layer.

There are three modes:

- **Asker** _(default)_ — ask questions in plain language and get data back.
- **Editor** — have your agent make validated changes to your semantic layer, verify them, and publish only when you confirm.
- **Builder** — have your agent build data apps and dashboards using Jedify's semantic functions.

Every mode shares the core question tools. Editor adds semantic-layer editing, versioning, and test sets; Builder adds function management and the SDK.

<Note>
**Building a dashboard or app?** Read [Connect](/mcp/connect) → [Semantic functions](/mcp/builder/semantic-functions) → [Examples](/mcp/builder/examples). **Evolving the semantic layer?** See [Editor tools](/mcp/editor/tools-reference). **Just asking questions?** See [Asker examples](/mcp/asker/use-cases).
</Note>

The release bundle ships three values files, which are your starting point: `values/jedify-infra.yaml` for the platform chart, and `values/jedify-be.yaml` plus `values/jedify-be-workers.yaml` for the application chart's two releases. Each chart's own `values.yaml` carries working defaults for everything those files don't set.

Where the bundle's file sets a different value from the chart, the **Default** column shows the bundle's value and names the chart's.

<Warning>
**Lists replace; maps merge.** A list in your values replaces the chart's whole list instead of adding to it. Set `gateway.healthChecks` to add one entry and you've removed the others, which shows up as a service answering `503` while its pods are ready. When you override a list, restate every entry you want to keep.
</Warning>

## jedify-infra

### Where pods run

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `nodeSelector` | map | `cloud.google.com/compute-class: autopilot-arm` and `kubernetes.io/arch: arm64` (bundle; the chart sets none) | The one node selector every component in the file reuses, through YAML aliases. Edit the block itself: aliases are resolved when the file is read, so `--set nodeSelector...` changes nothing. For amd64, replace both lines with `kubernetes.io/arch: amd64`. |

| --- | --- | --- | --- |

| --- | --- | --- | --- |

| `egressMasquerade.nonMasqueradeCIDRs` | list | `[192.0.2.0/24]` | Destinations that keep the pod's address. GKE requires at least one; the default is documentation address space nothing routes, so everything else is masqueraded. |

### Model proxy

| --- | --- | --- | --- |
| `litellm-helm.enabled` | bool | `true` | The bundled LiteLLM proxy. Set `false` to [use your own gateway](/self-hosted/model-gateway#use-your-own-gateway). |

### Realtime

| --- | --- | --- | --- |
| `sockudoApp.smKey` | string | `""`, required | The Secret Manager object holding `app_id`, `app_key` and `app_secret`. See [Realtime credentials](/self-hosted/reference/secrets#realtime-credentials). |
| `sockudo.redis.host` | string | `""`, required | `tofu output -raw redis_host`. The two sockudo replicas share subscriptions through it. |

| `sockudo.config.adapterDriver` | string | `redis` | Shared state between replicas. The chart refuses more than one replica with `local`. |
| `sockudoRoute.path` | string | `/pusher` | The path realtime is served on, on the application host. The web app uses the same value. |
| `sockudoRoute.timeoutSec` | int | `86400` | How long the load balancer lets one websocket live, busy or idle. GKE's default is 30 seconds. |
| `sockudoRoute.logging` | bool | `true` | The load balancer's request log for realtime |

### Gateway

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `gateway.enabled` | bool | `true` | |
| `gateway.name` | string | `jedify-gateway` | Must match `gateway.gatewayName` in `values/jedify-be.yaml`, or the application's routes attach to nothing |
| `gateway.className` | string | `gke-l7-rilb` | The kind of Google load balancer. See [DNS and TLS](/self-hosted/requirements#dns-and-tls). |
| `gateway.host` | string | `""`, required | The application host. The setup script reads it too. |
| `gateway.port` | int | `443` (bundle; chart `80`) | The listener's port: HTTPS when a certificate is configured |
| `gateway.addressName` | string | `""` | The name of a reserved address for the Gateway to claim. Empty: GKE allocates one with the Gateway and releases it with the Gateway. |
| `gateway.certMap` | string | `""` | A Certificate Manager map's name. Global class only. |
| `gateway.healthChecks` | list | `api` on `/api/readiness`, `mcp-server` on `/health` (both with `timeoutSec: 3600` and `logging: true`), Zitadel on `/debug/healthz`, Zitadel's sign-in UI on `/ui/v2/login/healthy` | One health check per backend service. GKE doesn't use pods' readiness probes; without an entry, a service whose root isn't `200` is marked down. `timeoutSec` raises the 30-second backend deadline for streamed responses, and needs `logging` set beside it. A list: keep every entry. |

### Certificates

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `tls.enabled` | bool | `true` (bundle; chart `false`) | Serve HTTPS from the Secret below |
| `tls.secretName` | string | `jedify-tls` | The Kubernetes TLS Secret in the `jedify` namespace. With `gateway.certMap` set, the chart creates a placeholder here, because the listener must name a Secret even when the map's certificate is served. |
| `cert-manager.enabled` | bool | `false` | The bundled cert-manager |
| `cert-manager.crds.enabled` | bool | `true` | Install its CRDs with it |

cert-manager needs Gateway API support turned on in its controller configuration. It isn't a feature gate: passing one changes nothing, and challenges stay pending with `gateway api is not enabled`.

```yaml
cert-manager:
  enabled: true
  config:
    apiVersion: controller.config.cert-manager.io/v1alpha1
    kind: ControllerConfiguration
    enableGatewayAPI: true
```

You create the issuer and the Certificate yourself; the Certificate writes the `jedify-tls` Secret.

### Reloader

Reloader restarts a workload when a Secret or ConfigMap it reads changes. It acts only in the namespaces listed and only on workloads that opt in.

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `reloader.enabled` | bool | `true` | |
| `reloader.reloader.watchGlobally` | bool | `false` | With an explicit list below, Reloader gets a Role per namespace and no cluster-wide permission |
| `reloader.reloader.namespaces` | list | `[jedify, jedify-be]` | Change it if you install into other namespaces |
| `reloader.reloader.autoReloadAll` | bool | `false` | Only workloads annotated to opt in are restarted |
| `reloader.reloader.reloadOnCreate` | bool | `true` | A Secret created after its workload counts as a change, so first-install pods don't stay stuck waiting for it |

## jedify-be

### Routing

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `gateway.host` | string | `""`, required | The application host: the same value as `gateway.host` in the platform values |
| `gateway.gatewayName` | string | `jedify-gateway` | The Gateway the routes attach to |
| `gateway.gatewayNamespace` | string | `jedify` (bundle; chart `traefik`) | The Gateway's namespace. The chart's default names a Gateway that doesn't exist here, and the routes then get no status and every request `404`s. |
| `gateway.corsMiddleware.enabled` | bool | `false` (bundle; chart `true`) | Must be `false`: GKE's Gateway rejects the middleware and the host stops serving. The API answers CORS itself. |

| `gateway.apiPathPrefixes` | list | `/api`, `/docs`, `/openapi.json`, `/.well-known` (bundle; chart `/`) | The API's paths. Everything else on the host goes to the web app. |

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `render` | string | `workers` | Makes this release render the queue workers and nothing else |
| `workers.grounding-worker.enabled` | bool | `true` | |

### Application environment

`externalSecret.plainEnv` in `values/jedify-be.yaml`. Plain environment variables override keys of the same name in your application configuration secret, so don't set a key here that belongs there, such as the Zitadel settings.

| Variable | Bundle value | Meaning |
| --- | --- | --- |
| `ENV` | `production` | One of `local`, `ci`, `dev`, `staging`, `production`. Any other value, or none, stops the API from starting with `NameError: _CORS_ORIGINS`. |
| `CORS_WHITELISTED_URLS` | Your application's origin | Browser origins the API accepts. See [CORS](/self-hosted/first-run#allow-your-origin-for-cors). |
| `USE_LITELLM_PROXY` | `true` | Send model calls through the proxy or your gateway |
| `EMBEDDINGS_VIA_BEDROCK` | `false` | Keep `false`: the other path needs Amazon Bedrock |
| `IN_MEM_VECTOR_SEARCH` | `true` | Firestore has no vector search, so search runs in the process over the stored embeddings |
| `MONGO_CONCURRENT_TX_OPS` | `false` | Writes inside a transaction run one after another; Firestore deadlocks on concurrent ones |
| `DATADOG_ENABLED`, `DD_TRACE_ENABLED` | `false` | No Datadog agent runs in your cluster; on, every component logs connection errors continuously |
| `MONGO_MTLS` | `false` | Firestore authenticates the workload's identity, not a client certificate |
| `MONGO_URI` | From `mongo_uri_command` | Use the printed URI unchanged |
| `MONGO_DB` | `tofu output -raw firestore_database_name` | |
| `STORAGE_BACKEND` | `gcs` | Explicit, never inferred |
| `STORAGE_BUCKET_NAME` | `tofu output -raw storage_bucket` | The one setting every storage path reads |
| `REDIS_HOST` | `tofu output -raw redis_host` | Without it, the application doesn't start |
| `REDIS_LOCAL_FORCE` | `true` | Selects the application's non-TLS Redis client on port 6379, which matches `redis_transit_encryption = "DISABLED"`. Redis traffic then crosses your VPC unencrypted. |
| `BE_URL`, `FE_URL` | `https://<your application host>` | The API's and the web app's public URLs. One host serves both. |
| `LITELLM_PROXY_URL` | The proxy's in-cluster URL | Not read by the application. Keep it equal to the next one. |
| `LITELLM_PROXY_API_BASE` | `http://jedify-infra-litellm.jedify.svc.cluster.local:4000` | Where model calls go. Fully qualified, because the proxy runs in another namespace. Never leave it unset. |

### What are Smart Scenarios?


These are a set of prompts grouped together that generate high quality complete presentations, reports, and docs that can be used for customer meetings, QBRs, team performance reviews, and more.


This enables faster, consistent, and accurate insights without requiring deep manual exploration.

### Common Use Cases


Here are a few examples of when Smart Scenarios can be used - especially for recurring analyses where you need to answer the same set of questions on a regular basis. By standardizing the investigation process, Smart Scenarios make it easy to track trends, compare results over time, and surface actionable insights consistently:


1. Monthly Business Review - track and compare key KPIs, revenue, and user metrics month over month.
2. Marketing Campaign Performance Analysis - monitor engagement, conversions, and channel performance across campaigns.
3. Customer Churn Tracking - measure churn rates, segment trends, and retention patterns over time.
4. Product Feature Adoption Review - assess usage trends for specific features by user type, geography, or plan.
5. Sales Pipeline Health Check - review win rates, deal velocity, and lead quality in each reporting cycle.

### Scenario


Your marketing and product teams were using different definitions for “Active Users.” To unify this, the company decides on a single version of truth. You’ll need to modify the existing semantic layer definition so that it reflects the agreed-upon logic and is consistent across all teams and reports.


### Steps to solve


1. Go to the relevant metric
2. Click "Modify" → "Edit base query SQL"
3. Modify the SQL query based on the new agreed-upon logic
4. Save your changes
5. Click "Modify" → "Edit context"
6. Edit the metric’s definition to reflect the new agreed-upon definition of “Active Users”.
7. Once all changes have been made, click "Submit changes". Jedify will notify you when the new entity is ready for review.
8. Review the new metric: Make sure that the changes were successfully implemented in both base query
9. SQL and definition, and that all related attributes and dimensions have been updated correspondingly. Then, approve or decline changes.
10. Verify the new metric: Ask Jedify questions about “Active Users” metric to make sure it successfully reflects the new business definition and logic.
11. Ready to go live? Click ‘Verify’ to publish.

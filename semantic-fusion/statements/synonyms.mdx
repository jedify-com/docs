This page explains how to create, edit, review, and publish changes to the Synonyms.


Navigate in app: Semantic Fusion Model → Semantic Statements → Synonyms


1. Click 'Add synonym' to add a new synonym.


![](/images/docs/image-9.png)


1. Input the term and it's expected output (e.g. "WAU" → "Weekly Active Users")
2. Save your changes by selecting "Add Synonym".
3. Test your changes by asking relevant questions in 'Ask Jedify'.
4. Publish your changes to be used across your entire organization.


**Please note: as with any changes to the Semantic Fusion model, your changes are only visible to data experts until they are published. **

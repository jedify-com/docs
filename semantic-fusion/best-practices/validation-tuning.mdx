---
title: "Semantic Entities Validation & Tuning"
icon: "bullseye"
---

Following the creation of new semantic entities, follow these steps and best practices to validate it:


1. Review the attributes that were automatically generated
  1. Check that the business definitions are correct, clear and meaningful
  2. Check that the SQL definitions are correct
  3. Modify/add attributes as needed
2. Create relations between newly created entities to existing entities
  1. Each relation only needs to be defined once from an entity to another
  2. For relations between a metric and a concept - create the relation from the metric entity
  3. For relations between concepts - create the relation from the more central entity
3. Begin testing by asking business questions
  1. Ensure Jedify interprets the questions correctly
  2. Ensure that the correct entities are selected to generate the response
  3. Check the SQL
4. If needed modify the entity/attributes: Entity definition, attributes, semantic dimensions, relations, or custom instructions.

To add a new data set to Jedify, follow the following steps:


![](/images/docs/image-8.png)


### 1. Define scope
- Define business metrics & questions
- What source tables are required to answer these questions

### 2. Add tables
- Grant Jedify access to the new tables
- Add the table to the Semantic Catalog from Jedify

### 3. Create semantic entities
- Create each of the new entities directly in Jedify (+ Add Entity from Semantic Fusion™ Model page)

### 4. Model Validation & Tuning
- Review attributes definitions that were automatically generated
- Test newly created entities by asking Jedify questions
- Iteratively tune the semantic definitions as needed (entity definition, attributes, relations and custom instructions)

### 5. Publish & Rollout
- Publish entities to make them available to business users in Jedify
- Communicate to end users

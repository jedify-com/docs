---
title: "New Data Onboarding Steps"
---

Too add a new data set to Jedify, follow the following steps:


![](/images/docs/image-8.png)


1. ## Define scope
  1. Define business metrics & questions
  2. What source tables are required to answer these questions
2. ## Add tables
  1. Grant Jedify access to the new tables
  2. Add the table to the Semantic Catalog from Jedify
3. ## Create semantic entities
  1. Create each of the new entities directly in Jedify (+ Add Entity from Semantic Fusion™ Model page)
4. ## Model Validation & Tuning
  1. Review attributes definitions that were automatically generated
  2. Test newly created entities by asking Jedify questions
  3. Iteratively tune the semantic definitions as needed (entity definition, attributes, relations and custom instructions)
5. ## Publish & Rollout
  1. Publish entities to make them available to business users in Jedify
  2. Communicate to end users

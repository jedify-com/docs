# Add Tables


When new tables are detected in connected schemas, the **Add Tables** flow allows data experts to bring them into the semantic catalog.


### How it Works


1. Click **Add tables**
2. A modal opens showing all **candidate tables** Jedify has discovered
3. Select one or more tables to add
4. Jedify processes the selected assets
5. You'll receive a notification once processing is complete


Processing time depends on table size (row count, column count, and overall metadata retrieval).
Once the operation finishes, the catalog displays the new tables with their inferred metadata.

For each object type, these edit actions are available:


### 1. Concepts


1. Edit base query SQL
2. Edit context
3. Add Concept
4. Delete Concept - **coming soon!**


### 2) Metrics


1. Edit base query SQL
2. Edit context
3. Add metric
4. Delete metric - **coming soon!**


### 3) Attributes


1. Add Attribute
2. Modify definition
3. Modify attribute SQL
4. Merge attributes
5. Delete attribute


### 4) Dimensions


1. Add dimension
2. Modify definition
3. Modify dimension SQL
4. Delete dimension


### 5) Relations - Coming soon!

## Background


From time to time, as business needs or definitions change, or when changes occur to the data platform structure, there may be a need to edit the semantic model entities.


Editing can include adding new entities, new attributes, modifying existing objects or deleting objects.


Each modification made to the semantic model will have an impact on the agentic flow processing user prompts, so it is important to understand what will be the impact of each change and test it thoroughly prior to releasing it to be used by the rest of the organization.


The flow described in this page will describe the different steps required to make a change, test it and publish it to be used by the rest of the organization.

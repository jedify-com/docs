One of the first steps to using Jedify is to set up the connections to the relevant data sources that would be used for Jedify to learn from and generate the Semantic Fusion™ Model.


This is done through the Data Connectors page


![](/images/docs/Screenshot_2025-08-13_at_3.37.42_PM.png)


Select the relevant connector and follow the instructions to setup that connection.

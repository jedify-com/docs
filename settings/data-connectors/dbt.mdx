title: "DBT Data Connector"
---

Connect to DBT by following the instructions and filling out the fields as shown below:


1. Create a service account - [Generate service account tokens](https://docs.getdbt.com/docs/dbt-cloud-apis/service-tokens#generate-service-account-tokens) in your dbt Cloud account
2. Find your project ID in the dbt Cloud project settings
3. Locate your environment ID - You can get the ID from a dbt URL or using the Admin API
4. Get your discovery API URL - [Discovery API endpoints](https://docs.getdbt.com/docs/dbt-cloud-apis/discovery-querying#discovery-api-endpoints)

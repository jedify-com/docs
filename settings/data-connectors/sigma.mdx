Connect to Sigma by following the instructions and filling out the fields as shown below:


1. Log into your Sigma workspace as an admin
2. Navigate to Administration > Developer Access
3. Create a new API client application
4. Copy the Client ID and Client Secret
5. Note your Sigma workspace URL

### Powered by Research Agent


Jedify uses the same advanced research agent from the main platform to process your questions: - Natural language understanding - Multi-step analysis when needed - Context-aware responses - Comprehensive data exploration


### Query Types


#### Simple Questions


- Direct metrics and KPIs
- Current status checks
- Basic comparisons


#### Complex Analysis


- Multi-dimensional investigations
- Trend analysis with explanations
- Cross-metric correlations


#### Root Cause Analysis


- Automated investigation of “why” questions
- Identification of contributing factors
- Data-driven explanations


#### Response Features


- **Clear answers:** Direct responses to your questions
- **Detailed analysis**: Step-by-step explanations when relevant
- **Actionable insights:** Practical findings you can act on
- **Share link**: Continue your analysis in the full Jedify platform for advanced visualizations and deeper exploration


#### Feedback System


After each response, you can:


- 👍 Thumbs up: Mark helpful responses
- 👎 Thumbs down: Flag responses that need improvement
- Your feedback helps improve the system’s accuracy

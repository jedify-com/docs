### Powered by Agent Mode


Jedify answers your questions with the same [Agent mode](/agent-mode) as the main platform:

- Natural language understanding
- Multi-step analysis when needed
- Context-aware follow-ups
- Comprehensive data exploration


### Query Types


#### Simple Questions


- Direct metrics and KPIs
- Current status checks
- Basic comparisons


#### Complex Analysis


- Multi-dimensional investigations
- Trend analysis with explanations
- Cross-metric correlations


#### Root Cause Analysis


- Automated investigation of “why” questions
- Identification of contributing factors
- Data-driven explanations


#### Response Features


- **Clear answers:** Direct responses to your questions
- **Live progress**: See each step Jedify takes while the answer streams in
- **Clarifying questions**: When your question is ambiguous, Jedify asks you to pick what you meant
- **Actionable insights:** Practical findings you can act on
- **Share link**: Continue your analysis in the full Jedify platform for advanced visualizations and deeper exploration


#### Conversation Features


- **Thread following:** In channels and group DMs, Jedify answers every reply in its threads, no mention needed
- **Muting:** Mute a thread to talk without Jedify answering each message. See [Communication Patterns](/settings/slack/communication-patterns#muting-a-thread)
- **Thread Context:** Ask about the discussion that came before your mention, when an admin turns it on
- **Suggested prompts:** Open Jedify's **Messages** tab to see questions you can start with


#### Jedify in Slackbot


You can also reach Jedify from Slackbot, Slack's built-in assistant. Slackbot uses Jedify to answer data questions with your own Jedify account and data permissions, the same as when you ask Jedify directly. Workspaces that connected Jedify before this was available need to reconnect once. See [Installation](/settings/slack/installation).


#### Feedback System


After each response, you can:


- 👍 Thumbs up: Mark helpful responses
- 👎 Thumbs down: Flag responses that need improvement
- Your feedback helps improve the system’s accuracy

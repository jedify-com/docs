## Research Agent Integration


When you ask a question in Slack, Jedify uses the **same research agent** that powers the main platform to:


1. Understand your natural language query
2. Analyze your connected data sources
3. Generate comprehensive insights
4. Return the results directly in Slack


This ensures you get the same quality of analysis whether you’re using the web platform or Slack.


## Session Continuity


- **Thread conversations:** All follow-up questions within a Jedify thread maintain session context
- **Platform transition: **Use the provided share link to continue your analysis in the Jedify platform with full visualization capabilities
- **Context preservation:** Your analysis session seamlessly transfers between Slack and the main platform
